# Sorteio de Filmes e Séries

Site que sorteia um filme ou série para você assistir. Você escolhe o
tipo (filme ou série), o gênero, a plataforma de streaming e a época,
e o site faz o sorteio.

🔗 **Site:** https://henry021.pythonanywhere.com/

## Tecnologias
- Python (Flask)
- HTML, CSS e JavaScript
- API do TMDB
- Hospedagem: PythonAnywhere

## Como rodar localmente
1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Crie um arquivo `chave.py` com o conteúdo: `CHAVE = "sua_chave_do_tmdb"`
4. Execute: `python app.py`
5. Abra http://127.0.0.1:5000 no navegador
